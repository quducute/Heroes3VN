## 💻 Mã nguồn

> [!IMPORTANT]
>
> - Mã nguồn được phát hành dưới **giấy phép [MIT](LICENSE)**
> - Prerequisites: **JavaScript**, **HTML/CSS** và **Rust**

| Thư mục                 | Nền tảng           | Công nghệ / Công dụng                                     |
| ----------------------- | ------------------ | --------------------------------------------------------- |
| **`shared/`**           | Dùng chung         | Nội dung, hình ảnh và giao diện PC dùng chung cho các bản |
| **`web/`**              | Web (GitHub Pages) | React + Vite + Tailwind CSS + GitHub Actions              |
| **`desktop/`**          | Windows            | React + Vite + Tailwind CSS + Electron                    |
| **`desktop-webview2/`** | Windows (WebView2) | React + Vite + Tailwind CSS + Tauri v2                    |
| **`mobile/`**           | Android, iOS       | React Native + Expo + Tailwind CSS (Uniwind)              |
| **`release/`**          | Desktop, Mobile    | Chứa các file thành phẩm sau khi build                    |

### Kiến trúc hệ thống

### Tải mã nguồn về máy

```bash
# B0. Cài Git (bỏ qua nếu máy đã có)
winget install -e --id Git.Git

# B1. Clone repo về máy
git clone https://github.com/quducute/Heroes3VN.git

# B2. Cài Node.js LTS
winget install -e --id OpenJS.NodeJS.LTS
```

### Bản Web

```bash
# B1. Vào thư mục bản Web
cd Heroes3VN/web

# B2. Cài dependencies
npm install
```

| Lệnh               | Công dụng                                           |
| ------------------ | --------------------------------------------------- |
| `npx eslint .`     | Dùng ESLint để rà soát code                         |
| `npm run build`    | Build web ra `dist/` kèm trang tĩnh cho từng route  |
| `npx vite preview` | Mở bản build trong `dist/` để test trước khi deploy |

### Bản Windows

```bash
# B1. Vào thư mục bản Windows
cd Heroes3VN/desktop

# B2. Cài dependencies
npm install
```

| Lệnh              | Công dụng                                             |
| ----------------- | ----------------------------------------------------- |
| `npx eslint .`    | Dùng ESLint để rà soát code                           |
| `npm run preview` | Build rồi mở app test (đầy đủ chức năng)              |
| `npm run build`   | Build rồi đóng gói file `.exe` portable ra `release/` |

### Bản Windows WebView2

```bash
# B1. Cài Visual Studio Build Tools
winget install -e --id Microsoft.VisualStudio.2022.BuildTools

# B2. Cài Rust
winget install -e --id Rustlang.Rustup

# B3. Vào thư mục bản Windows WebView2
cd Heroes3VN/desktop-webview2

# B4. Cài dependencies
npm install
```

| Lệnh            | Công dụng                                             |
| --------------- | ----------------------------------------------------- |
| `npx eslint .`  | Dùng ESLint để rà soát code                           |
| `npx tauri dev` | Mở app test live (đầy đủ chức năng)                   |
| `npm run build` | Build rồi đóng gói file `.exe` portable ra `release/` |

### Bản Mobile

```bash
# B1. Cài EAS CLI (để build file cài)
npm install -g eas-cli

# B2. Đăng nhập tài khoản Expo
eas login

# B3. Vào thư mục bản Mobile
cd Heroes3VN/mobile

# B4. Cài dependencies
npm install

# B5. Gắn EAS_PROJECT_ID vào file .env tạo từ mẫu (thay ... bằng ID của project trên expo.dev)
cp .env.example .env
echo "EAS_PROJECT_ID=..." > .env
```

| Lệnh                                 | Công dụng                                                                 |
| ------------------------------------ | ------------------------------------------------------------------------- |
| `npx eslint .`                       | Dùng ESLint để rà soát code                                               |
| `npx expo start`                     | Chạy dev server để test app qua Expo Go                                   |
| `eas build -p android -e preview`    | Đóng gói file `.apk` để cài trực tiếp vào máy                             |
| `eas build -p android -e production` | Đóng gói file `.aab` để đưa lên Google Play Store                         |
| `eas build -p ios -e production`     | Đóng gói file `.ipa` để đưa lên App Store (cần tài khoản Apple Developer) |
